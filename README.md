# Coworking Lorient, esquisse

Page unique pour mettre des bureaux en location. Esquisse du 12/09/2026, faite avant que
le client donne ses visuels et ses informations.

- Une seule couleur: le jaune, le noir ecrit dessus.
- Six visuels en 16/9, pleine largeur, en deux carrousels.
- Cinq informations: le bureau est la, il est libre, il est propre, voila le prix,
  appelez-nous.

**Ce qui attend leurs informations** est souligne en pointille dans la page: le nom, le
telephone, l'adresse, les horaires, les tarifs, les capacites. Au survol, la page dit
"a confirmer".

Le formulaire n'envoie rien pour l'instant: il reste a brancher sur leur adresse mail.

Aucune dependance: un seul fichier `index.html`, rien a installer, rien a compiler.
